# Screenshots

Place the project's screenshots in this folder.

Recommended filenames referenced by the root `README.md`:

- `dashboard.png`
- `network.png`
- `usb.png`
- `commands-events.png`
- `user-activity.png`
- `registry.png`
- `threat-center.png`
- `excel-export.png`

After adding the images, GitHub will display them automatically in the main README.
